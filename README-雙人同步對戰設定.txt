DON'T LIKE YOUR MOM v0.6.0｜雙人同步好友對戰更新
===============================================

【重要】本包只含有修改的程式，不包含 99 張既有照片。

一、更新 GitHub（請保留原本的排行榜和遊戲素材）
  1. 解壓縮 ZIP。
  2. 將 index.html、style.css、script.js、sw.js 覆蓋到現有 GitHub 專案根目錄。
  3. 將新的 live-duel.js 放到根目錄。
  4. Commit / Push，等 GitHub Pages 部署完成。
  5. 不要把 setup-duel-rooms.sql 放進網頁路徑給遊戲執行；該檔是給 Supabase SQL Editor 使用。

二、在 Supabase 啟用雙人房間（必做一次）
  1. 開啟你原本用來儲存全球排行榜的 Supabase 專案。
  2. SQL Editor → New query。
  3. 複製 setup-duel-rooms.sql 全部內容，點 Run。
  4. 不要再建新的 Supabase 專案、不需重設排行榜、不用更換 leaderboard-config.js。
  5. 本更新新增 dlym_duel_rooms 表與 5 支 RPC。原本排行榜 SQL 不受影響。

三、玩家使用流程
  房主：首頁按「挑戰朋友」→ 輸入暱稱 →「建立房間」→「分享邀請連結」。
  朋友：點邀請網址 → 輸入暱稱 →「加入這個房間」。
  雙方都按「我準備好了」，同一組照片在預定時間一起開始 45 秒。
  結束後雙方比分。若其中一位先失敗，等另一位完成即可知道輸贏。
  房間有效期 2 小時；一個房間兩個玩家。下一局重新建立房間。
  原本一般模式仍然存在，不受影響。

四、與「先玩完再分享」版的差別
  此版不再讓第一人先玩完才產生目標分數。
  目前同步使用 Supabase 房間 API 輪詢（約 1 秒一次），依伺服器安排的開賽時間倒數，
  不是高頻 WebSocket 即時房間；遇到網路中斷或 iOS 背景暫停，可能造成開賽延遲。

五、安全與限制
  每個玩家得到自己的隨機房間憑證，不允許前端直接讀寫房間資料表。
  房間成績由客戶端提交，有基礎範圍與時長檢查，仍不能當作完整的反作弊證明。
  房間比分是朋友間趣味比賽，不能自動當成可信任的全球排行榜戰績。
  原本排行榜維持不變。
  請勿將 Supabase secret/service_role 金鑰或資料庫密碼放進 GitHub。

故障排除
  - 顯示找不到 dlym_duel_create：確認 SQL Editor 已執行整份 SQL，並等 API schema cache 更新。
  - 房間已滿：只能兩個人，房主重新建立另一個房間。
  - 相同照片順序不能開始：雙方都更新到相同遊戲素材版本後，再重新分享連結。
  - 朋友進不了房間：確認收到的網址以新 GitHub Pages 網址開頭，而且 ?room=... 參數完整。
  - iPhone 還顯示舊版：關閉遊戲重新開啟，必要時移除主畫面捷徑再加入。
