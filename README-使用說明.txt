# DON'T LIKE YOUR MOM — v0.5.1 iPhone App 圖示更新

這個 ZIP 只含有修改過的檔案，不包含人物照片，不會修改排行榜、音效、遊戲時間或 72 張遊戲照片。

操作：
1. 解壓縮 ZIP。
2. 將 index.html、manifest.webmanifest、sw.js 和 assets/ 資料夾內 3 張新圖示上傳至原本 GitHub 遊戲專案相對應的位置。
   - 保留原本 assets/profiles 的照片，不要刪除或更換。
   - 保留你自己設定好的 leaderboard-config.js（雲端金鑰設定），不要覆蓋它。
3. Commit changes，等 GitHub Pages 更新後，在 iPhone Safari 開啟遊戲網站。
4. 若主畫面原有的圖示仍是字母 D，請先截圖保留原本遊戲紀錄，再移除舊的「主畫面圖示」並從 Safari 使用「分享 → 加入主畫面 → 打開為網頁 App → 加入」。

設計：使用使用者選定的正方形桃紅愛心媽媽 Logo，原圖僅縮成 App 圖示尺寸。
