DON'T LIKE YOUR MOM v0.8.8｜玩家留言板（更新檔）

功能：
1. 首頁新增「💬 玩家留言板」，所有玩家都能查看審核通過的留言。
2. 玩家不需要手動註冊：沿用照片投稿的 Supabase 匿名登入。
3. 分類有「閒聊」「遊戲建議」「問題回報」，暱稱 2–18 字、留言 6–400 字。
4. 新留言先送審，不會立刻公開；站長可以通過或拒絕。
5. 已公開留言可檢舉，站長可以下架、置頂或取消置頂。
6. 每個匿名身份 90 秒最多一則、24 小時最多六則；每日最多十次檢舉。
7. 資料庫禁止直接讀取待審留言，只有管理員白名單可管理。

【第一步：Supabase，務必先做】
登入原本 Supabase 專案 → SQL Editor → New query → 貼上 setup-message-board-v088-iphone.txt 的全部內容 → 按 Run。
SQL 也放在 ZIP 內，方便用電腦複製。若尚未裝過「照片投稿」SQL，先完成原本的管理員白名單設定。
執行成功後才能正常發文／審核；不會修改現有排行榜及照片。

【第二步：GitHub Pages 更新】
解壓縮本 ZIP，依照相同路徑上傳專案根目錄：
覆蓋：index.html、script.js、style.css、admin.html、sw.js。
新增：board.html、board.js、board.css、board-admin.html、board-admin.js。
其餘檔案僅是說明／SQL，不需要放進網站也可以。
絕對不要覆蓋 leaderboard-config.js。這次沒有任何照片要重傳。
本版接續 v0.8.7（原有 205 張內建照片），若尚未部署 v0.8.7，請先部署。

【第三步：測試】
1. 開首頁確認版本 v0.8.8，點「💬 玩家留言板」。
2. 用一個玩家裝置留言「好玩！希望有生存模式」，看到「等待審核」。
3. 站長到 https://vmylife.github.io/Don-t-like-your-mom/board-admin.html
   使用原本照片審核的 Email／密碼登入，將待審留言設為「審核通過」。
4. 另一支手機重新整理 board.html，留言就會出現在公開列表。
5. 測試檢舉、置頂、下架。已下架留言會從公開頁消失。

【注意】
- 留言不是即時聊天：採用先審後公開，避免垃圾訊息、不雅內容及個資外洩。
- 匿名身份防洗版限制無法阻止有心人士建立新身份；若未來惡意流量增加，可再加 CAPTCHA。
- 管理員使用原本 dlym_photo_admins 白名單，若未授權，不能審核。
- 網頁上不會暴露 Supabase secret/service_role，也沒有將資料庫表格設成公開可直接查詢。
- 因為是新功能，舊遊戲不會出現歷史留言；上線後才會開始蒐集。
- 更新失敗或還看到舊版時，檢查 GitHub Pages 最新部署與 Safari 網站快取。
