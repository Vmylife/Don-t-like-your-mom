DON'T LIKE YOUR MOM v0.7.4｜審核大小與排行榜順序調整

本次只有 2 個遊戲功能修改：
1. 管理員審核頁的待審照片顯示實際檔案大小（例如：📦 檔案大小：186 KB）；已公開照片也嘗試讀取大小（伺服器不提供 Content-Length 時會顯示無法取得）。
2. 排行榜分頁由左至右：📅 每日／🌍 歷史排行／🏅 歷日冠。點開排行榜預設每日榜。

【上傳 GitHub】
把 ZIP 裡以下 7 個檔案放到 GitHub 專案根目錄覆蓋：
- admin.html
- community-ui.js
- community.css
- index.html
- leaderboard.js
- script.js
- sw.js

【注意】
- 不需要執行新的 Supabase SQL，也不需要重新上傳照片。
- 不要覆蓋你原本設定好的 leaderboard-config.js。
- 待審檔案大小取自管理員已下載的私人照片 Blob，為實際下載大小；未額外下載一次圖片。
- 已公開照片大小使用 HEAD 讀取，避免額外下載完整圖片；若伺服器不提供大小資訊會顯示「無法取得」。
- 修改後，開啟首頁確認 v0.7.4；管理員頁也請重新載入。若手機仍顯示舊版，完全關閉頁面再開啟。
- 本次未修改排行榜的分數排序，也未變更投稿審核權限。
